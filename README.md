# XSpeak skills repository

This is the home of XSpeak's curated AI skills.

Currently the repository contains Analyzers, skills that process conversation transcripts and give you a result. Analyzers are used in two places:
- AI Actions
- Real-Time Insights panel

## Contributing

It's not possible to contribute to this repository yet. Pull requests to improve existing skills or add new curated skills are planned to be accepted in the future.
